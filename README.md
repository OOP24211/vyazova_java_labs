# Проект WatchTogether

Веб-приложение для совместного просмотра видео с YouTube и общения в режиме реального времени.

## Описание проекта
* **Real-time Синхронизация Плеера:** Мгновенная передача команд воспроизведения, паузы и перемотки (seek) всем участникам комнаты.
* **Бесшовное подключение «на лету»:** Реализован сложный алгоритм входа в комнату — новый пользователь автоматически запрашивает текущее состояние бэкенда (`room.getState`), дожидается полной готовности YouTube API (`onReady`) и плавно перематывает видео на ту же секунду, на которой находятся остальные.
* **Защита от бесконечного цикла («эхо»):** Логика фронтенда изолирована с помощью useRef-флагов синхронизации (`isSyncing`), что предотвращает зацикливание отправки сокет-событий при программном управлении плеером.
* **Учет онлайна по сессиям:** Бэкенд динамически отслеживает жизненный цикл WebSocket-сессий. При закрытии вкладки или потере интернета срабатывает триггер `SessionDisconnectEvent`, онлайн пересчитывается, а пустые комнаты автоматически вычищаются из памяти.
* **Встроенный чат:** Полноценный real-time чат внутри комнаты для живого обсуждения видео.
* **Автогенерация БД:** Благодаря интеграции с Hibernate ORM, база данных PostgreSQL автоматически разворачивает необходимую структуру таблиц (схему) при первом же запуске бэкенда.

## Технологический стек
* **Бэкенд:** Java 17, Spring Boot, Spring Data JPA, Spring WebSocket (протокол STOMP)
* **Фронтенд:** React, библиотека @stomp/stompjs для сокетов, react-youtube для работы с плеером
* **База данных:** PostgreSQL, Hibernate ORM

## Как запустить проект локально

### 1. Подготовка базы данных
1. Запустите СУБД PostgreSQL.
2. Создайте пустую базу данных с именем `watchtogether`.

### 2. Запуск бэкенда
1. Откройте папку `backend` в среде разработки (например, IntelliJ IDEA).
2. Проверьте настройки подключения к базе данных в файле `src/main/resources/application.properties`. При необходимости укажите ваш пароль от PostgreSQL.
3. Запустите главный класс `DemoApplication.java`.
4. Бэкенд запустится на порту `8080`. Зависимости и таблицы в базе данных создадутся автоматически благодаря Hibernate.
